## Модель и признаки

37 признаков: склад, артикул и категории; дневные средние и частота спроса; последние полные недели; давность/тренд; signed stock, резервы и производное покрытие; номер и календарь целевой недели. mean_all использует всю предоставленную историю, а короткие признаки сохраняют собственные rolling-окна. Будущие продажи, остатки и категории в признаки не попадают.

Ансамбль 0,3 × hurdle + 0,7 × LightGBM на log1p недельного quantity. Hurdle возвращает Poisson-величину при P(продажи за неделю)≥0,5 и ноль ниже порога. На первом окне из 18 фиксированных вариантов выбрано округление **после недельного прогноза**, на втором оно подтверждено. Дробные значения разрешены контрактом, округление — выбранная настройка этой модели.

Финальные три бустера используют 151/188/99 деревьев (классификатор hurdle / регрессор hurdle / log1p-регрессор). Финальный refit: 16 временных срезов, 1 160 298 недельных обучающих строк. Срезы у правой границы содержат только доступные полные target-недели.

Финансовые признаки не добавлялись в рабочую модель. Для их дальнейшего использования реализована проверенная exp-before-sum функция с нулевым вкладом исходного null discount_sum; исправлен такой же расчёт в историческом m5_lab. Quantity и stock не экспоненцируются. Собственный log1p таргета обращается через expm1.

Новый каталог: `artifacts/weekly-verified-20261027/`. Origins: **15.02.2026** (выбор, факт 16.02–19.04) и **24.05.2026** (подтверждение, факт 25.05–26.07). Контрольное занижение общего объёма — **−18,8262%**. Это отличается от метрики абсолютного Bias по сериям. Проблема занижения сохраняется и явно отражена в сегментных отчётах. Относительно неокруглённого weekly ансамбля округление улучшило SMAPE/WAPE, но ухудшило RMSE/Bias/RMSLE; оно принято по заранее установленному взвешенному критерию, а не по утверждению об улучшении каждой метрики.

Локальный нормализованный min-max score — 0,78904 относительно last_week. Это не официальный ранг соревнования. Дневные SMAPE≈29,59% прежней версии с этим недельным результатом напрямую не сравниваются.

Проверка выбранной калибровки на уже просмотренном ею факте помечена diagnostic_calibration_seen_truth; независимое подтверждение следует брать из decision.json. SMAPE raw модели по weekday — 137,85–137,90%, WAPE — 53,53–53,68%. Этот описательный тест не участвовал в выборе; окна факта перекрываются и не являются семью независимыми fold. ## HTTP и Docker

Результаты полных HTTP-проверок записаны в `forecast-container/logs/weekly_runtime.json`; контейнерные — в `weekly_docker.json`.

На Windows/Python 3.10 два полных POST заняли **45,46 и 42,29 секунды**, GET CSV — **0,168 с**, GET JSON — **0,093 с**. Измеренный пик рабочего набора процесса сервиса — **2,603 GiB**. Два POST побайтно одинаковы; значения совпадают с подготовленным CSV. Полные GET, три варианта фильтра, CSV/JSON и Bash HTTP-самопроверка прошли. Файловая и HTTP-сериализация могут иметь разные окончания строк, поэтому равенство submission проверяется по ключам и значениям.

Проверяются два полных POST, побайтная повторяемость, совпадение с submission, CSV/JSON и фильтры GET. Для Docker предусмотрен запуск без сети с жёстким лимитом 7 GiB и 8 CPU, запросы выполняются по loopback внутри контейнера. Обучающие CSV не включаются в образ; тестовый вход передаётся отдельно как содержимое запроса.

Проверка Docker/Linux **пройдена**: два полных POST — **36,26 и 34,98 с**, GET CSV — **0,130 с**, GET JSON — **0,077 с**. Повторные POST побайтно одинаковы, все 78 993 строки совпали с submission по ключам и значениям, фильтры и JSON согласованы. NetworkMode=none проверен через inspect. Расчёт завершён под жёстким лимитом **7 GiB RAM / 8 CPU**; точный пик контейнера не измерялся. Размер образа — **305 520 979 байт** (около 291 MiB). Первичная сборка со скачиванием зависимостей завершилась успешно; измеренные **2,07 с** относятся к повторной сборке с кэшем. Это замеры данной машины, не гарантия времени на любом оборудовании.

## Ограничения и передача

Единственная внешняя недостающая часть основного контракта — официальный каталог пар. До его появления нельзя заявить, что наблюдаемые 8 777 пар совпадают со скрытым эталоном. Fallback для пар без истории реализован и проверен на корректность, но его качество на неизвестном официальном ассортименте не установлено.

Кэш API один на процесс; нет отдельного пользовательского веб-интерфейса, очереди и истории запусков. Проверка двух сезонных окон и описательного weekday-среза не гарантирует одинакового качества во всех режимах.

Архив находится рядом с новым CSV и включает исходники, модель, документацию, тесты, примеры входов, протокол/решение/хеши и manifest. Сырые обучающие CSV, старые эксперименты и секреты в архив не включаются. Финальный файл не публиковался, сообщения организаторам не отправлялись; пользователь самостоятельно выбирает момент передачи.
