# Выполнение плана улучшений недельной модели

Начато 28.10.2026 по новому поручению пользователя: выполнить рекомендации [повторного аудита](RECHECK_TZ_AND_IMPROVEMENTS_RU.md), включая эксперименты и обучение. Прежний запрет обучения относился к сессии аудита и этим поручением снят. Работа выполняется одним агентом.

## Протокол и исходная модель

До изменения сохранены исходники и три файла production-модели в локальном `artifacts/recovery/pre-improvements-20261028/`, с manifest SHA-256. Исторические результаты в `experiments/evidence/` не переписываются.

Новый запуск: `artifacts/improvements-20261028-r1/`. До обучения зафиксированы SHA входных CSV, исходников ML-пути, самой исследовательской программы и сетки. Три окна разработки: origins 19.10.2025, 18.01.2026, 22.03.2026. Контроль: origin 24.05.2026. Каждая цель — девять полных недель; train/early-stopping labels разделены, оценочные веса обучаются только до своего origin. Финальное обучение ограничено 26.07.2026.

**История уже исследовалась ранее.** Этот протокол даёт сравнение на исторических out-of-sample прогнозах с фиксированным отбором, но не создаёт совершенно новый, прежде никем не просмотренный holdout. После фиксации кандидата контроль используется один раз; другие варианты по нему не выбираются.

Зафиксированы 927 рецептов. Сравниваются пять метрик, их локальная взвешенная сумма отношений к rounded baseline, устойчивость по origin и ошибки сегментов. Локальная сумма не является официальным leaderboard. Продвижение требует заранее заданного выигрыша минимум 0,5%, ограничения SMAPE и улучшения минимум трёх метрик. При отказе контроля прежний production сохраняется.

## Реализованные направления

- Совместная сетка округления/порогов, весов ансамбля, gate, scale, сегментных поправок и смешивания с простыми прогнозами.
- Абляции base / calendar / dynamics / monetary / all на одинаковых данных и границах.
- Недельные Poisson, Tweedie, MAE, Quantile, CatBoost; смешивания с основным ансамблем.
- Четыре группы спроса с общим fallback, определяемые только из прошлой доли нулевых недель и вариативности положительного спроса.
- Недельные TSB и Croston-SBA как самостоятельные компоненты; единицы измерения — продажи за неделю, произвольного деления на два нет.
- Apportion по дробным остаткам с сохранением округлённой суммы по горизонту; целочисленность не навязывается исходным данным.
- Денежные признаки: exp каждого предоставленного log-значения до sum; null discount даёт нулевой вклад. Будущие денежные поля не используются.
- Недельная EWMA, вариативность, ADI, межскладские/категорийные средние и доли, календарная нормализация исторического спроса.
- Версия препроцессора 4 для research-модели; версия 3 остаётся совместимой с сохранённым production до решения о продвижении. Обучение и API используют общий код признаков и прогнозирования.

## Календарь РФ

Календарь локальный, без сетевых запросов при инференсе. Учитываются федеральные праздники, автоматические переносы и опубликованные ежегодные переносы 2024–2026 годов. Для каждого origin применяются только уже опубликованные к этому моменту ежегодные решения; неизвестные переносы не выдумываются, выставляется признак неполного знания. Региональная привязка складов не угадывается. Праздники не обнуляют спрос автоматически.

Источники: [Минтруд: федеральные праздники и правило совпадения выходных](https://mintrud.gov.ru/labour/relationship/351), [постановление № 1314 на 2024 год](https://publication.pravo.gov.ru/document/0001202308180053), [постановление № 1335 на 2025 год](https://publication.pravo.gov.ru/document/0001202410040023), [копия подписанного документа 2025](https://storage.consultant.ru/ondb/attachments/202410/04/iddoc_286124_idnews_56549_Vyhodnye_2025_sVh.pdf), [постановление № 1466 на 2026 год](https://static.government.ru/media/files/4jeB8hNKm69ggOa9yDiYOli6YoAyM21i.pdf). Содержание документов проверено через доступные публикации; часть официальных URL при прямом открытии отвечала таймаутом.

Соответствие анонимизированных дат реальному календарю и региональная привязка не подтверждены организаторами. Поэтому календарь проверяется отдельной абляцией. Признаки годов с неизвестными ежегодными решениями используют только общие законодательно заданные правила с явным transfer_known=0.

## Выполнение и проверки

До основного запуска прошли **106 тестов**, включая новые проверки exp-before-sum, независимости признаков от будущего, известных и ещё не опубликованных переносов, недельных единиц TSB/SBA, apportion и совпадения сохранённой модели с Predictor.

Основное исследование, подтверждение и финальное обучение завершены. Расширенный набор проверок: **113 passed, 0 failed**. Прежняя deprecation warning Starlette/httpx не влияет на результат.

## Итог выбора и контроль

Выбран профиль **dynamics**: прежние 37 признаков плюс 12 признаков недельной динамики и иерархии. Препроцессор формирует 68 доступных колонок, выбранные бустеры используют 49. Сохранились веса hurdle/log1p LightGBM 0,3/0,7 и gate 0,5. Для рядов с ≥45 днями продаж за 90 дней выбран множитель 1,1; применяется недельное округление. Среднее локальное отношение по трём окнам разработки — **0,990771**, улучшены все пять метрик в среднем.

| Метрика | Прежняя weekly база, заново обученная до origin | Кандидат |
|---|---:|---:|
| SMAPE, % | 59,840814 | 59,321425 |
| WAPE, % | 46,895428 | 46,328391 |
| RMSE | 3,325110 | 3,214917 |
| Абсолютный Bias по сериям, % | 72,844814 | 72,611677 |
| RMSLE | 0,506646 | 0,503019 |

Контроль прошёл заранее заданное правило: локальное отношение **0,987593**, улучшены **5/5** метрик. SMAPE снизился на 0,5194 процентного пункта, занижение общего объёма — с 18,8262% до 13,6729%. Прирост умеренный: дополнительный подбор помог, но не объясняет всю разницу с дневным SMAPE.

Праздничная неделя контроля: SMAPE 59,4465 → 58,7525%; обычные недели: 59,8901 → 59,3925%. Это результат dynamics-рецепта; его нельзя приписывать специальным календарным колонкам. В отдельных сегментах улучшились не все показатели: у регулярных рядов Bias и RMSLE немного ухудшились; у редких WAPE всё ещё около 99,2%. Редкий спрос полностью не решён.

## Какие направления помогли

С одинаковой базовой постобработкой среднее локальное отношение: calendar **0,9969**, dynamics **0,9951**, monetary **0,9990**, all **0,9930**. Календарь помог зимнему и весеннему окнам, но ухудшил осеннее. Лучший совместный рецепт — dynamics с поправкой регулярных рядов; специальные признаки праздников РФ **не включены в выбранные бустеры**. Они реализованы и доступны для повторных исследований.

Групповые модели, CatBoost, отдельные Poisson/Tweedie и самостоятельные TSB/SBA не стали итоговым решением. Отрицательные результаты, все 927 вариантов на каждом окне, параметры и разрезы сохранены в [новой серии экспериментов](../../experiments/IMPROVEMENTS_20261028_RU.md). Многократное увеличение positive weights, маскирование stock=0 и увеличение лимита деревьев без оснований не повторялись: аудит относил их к низкому приоритету с отрицательными прошлыми результатами.
