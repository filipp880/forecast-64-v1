# Итоговый отчёт: недельный прогноз продаж

Версия 28.10.2026. [Полный отчёт улучшений](IMPROVEMENTS_EXECUTION_RU.md), [все новые эксперименты](../../experiments/IMPROVEMENTS_20261028_RU.md). Исходное внедрение weekly от 27.10 сохранено в [IMPLEMENTATION_WEEKLY_RU.md](IMPLEMENTATION_WEEKLY_RU.md).

Модель прогнозирует суммы quantity за девять недель. История ограничена 26.07.2026, конкурсный прогноз начинается 27.07.2026. Дубли дневного stock суммируются, знак и резервы сохраняются. Денежные признаки исследованы с exp-before-sum; внутренняя log1p-ветвь таргета обращается через expm1.

После 927 рецептов / 11 обучаемых семейств / трёх окон разработки выбран dynamics-ансамбль: hurdle и log1p LightGBM, 49 используемых признаков, масштаб 1,1 для рядов с ≥45 днями продаж за 90 дней и округление. Календарь РФ реализован и проверен отдельной абляцией, но специальные праздничные колонки не вошли в выбранный набор. Финальные веса обучены на 1 160 298 строках из 16 origin; деревья — 120/188/88.

Историческое подтверждение 25.05–26.07.2026: SMAPE **59,3214%**, WAPE **46,3284%**, RMSE **3,2149**, абсолютный Bias по сериям **72,6117%**, RMSLE **0,5030**. Все пять лучше прежней weekly базы; объёмный недопрогноз уменьшился с 18,8262% до 13,6729%. Период просматривался прежде: это out-of-sample сравнение фиксированного кандидата, не совершенно новый holdout и не официальный score конечного CSV.

CSV: `submission/weekly_improved_20261028/forecast.csv`, 78 993 строки / 8 777 пар / девять недель. Повторные расчёты одинаковы, дублей/NaN/inf/отрицательных значений нет. Официального каталога пар нет, покрытие отмечено provisional. Старый production сохранён для отката.

Проверки: **113 тестов**, signed-stock audit, семь дней отсечки на sample-датах, неизвестная пара, Python offline guard, native HTTP и Bash. Native POST **46,10/46,56 с**, пик сервиса **2,75 GiB**. Docker/Linux без сети при 7 GiB/8 CPU: POST **52,56/38,86 с**, GET CSV **0,158 с**, JSON **0,070 с**, образ **305,2 MB**. Сборка 8,93 с использовала кэш зависимостей; точный пик памяти контейнера не измерялся. Значения Docker/API совпали с CSV.
