# Итоговый отчёт: недельный прогноз продаж

Актуальный подробный отчёт: [IMPLEMENTATION_WEEKLY_RU.md](IMPLEMENTATION_WEEKLY_RU.md). Версия от 27.10.2026; исходное дневное решение сохранено в artifacts/recovery/legacy64-20261027/.

Рабочее решение прогнозирует суммы quantity за девять недель. Конкурсное обучение и признаки ограничены 26 июля 2026 года; CSV начинается 27 июля. API определяет следующий понедельник автоматически.

Новая модель — direct weekly ансамбль LightGBM: hurdle и log1p-регрессор, 37 признаков, округление недельного результата выбрано по фиксированному протоколу. Остатки сохраняют знак, повторные дневные stock-ключи суммируются. Признаки и веса согласованы версией предобработки и хешами.

На независимом контрольном окне 25.05–26.07.2026: SMAPE 59,8408%, WAPE 46,8954%, RMSE 3,3251, абсолютный Bias по сериям 72,8448%, RMSLE 0,5066. Это историческая оценка, не официальный score конечного submission. Суммарный объём занижен на 18,8262%.

Готовый локальный результат: submission/weekly_observed/forecast.csv, 78 993 строки на 8 777 пар. Два расчёта совпадают, отрицательных/неконечных значений и повторных ключей нет. Официального справочника пар нет, поэтому покрытие явно отмечено provisional; соответствие скрытому эталону не заявляется.

Проверки кода и происхождения: 102 теста; полный signed-stock audit; описательная проверка семи weekday; запрет сетевых Python-вызовов при загрузке и sample-инференсе. Полные native HTTP и Bash проверки прошли. Docker/Linux проверен без сети под лимитом 7 GiB/8 CPU: POST 36,26/34,98 с, совпадение с submission по значениям, GET/JSON/фильтры согласованы. Размер образа 305,5 MB. Фактические измерения — в logs/weekly_runtime.json и logs/weekly_docker.json внутри forecast-container.

Исходный архив проверки: submission/weekly_observed/forecast_weekly_submission.zip. Он содержит код, модель, CSV, каталог наблюдаемых пар, инструкции и свидетельства проверки; исходные train-CSV и старые модели исключены.
