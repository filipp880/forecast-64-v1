# Результат независимой проверки

`verified_summary.json` — компактный итог двух хронологических OOF-окон, выбора и подтверждения кандидата. Это историческая проверка рецепта модели, не официальный score жюри и не оценка будущего submission по неизвестным фактам.

Для воспроизведения нужны полные данные организаторов, отдельно размещённые в корневом `data/`, и команды из раздела 5 README. Прогнозы, оценочные модели и подробный протокол генерируются в локальном `artifacts/verified/` вне Git.

Старые `report_*.json` и `*lab.json` исключены из текущей версии Git: они остаются на диске и в истории коммитов. Для части старых стендов обнаружены пересечения целевых периодов и проблемы оценки; эти числа не подтверждают качество финального решения.
