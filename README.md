# Прогноз продаж на 64 дня — решение

Решение задания `Nonton_Backend_TZ_Forecasting_API`: контейнер с FastAPI-сервисом,
который принимает историю продаж и остатков (CSV) и отдаёт прогноз `quantity`
на 64 календарных дня по парам «склад × артикул».

Самодостаточное решение для сдачи — в [`forecast-container/`](forecast-container/README.md):
финальная модель `blend` (0.3 × hurdle + 0.7 × lgbm), строгая валидация и бэктест
по пяти метрикам ТЗ, самопроверка API и разбор всех проверенных гипотез (включая
отклонённые) с замерами. Обученная модель уже в репозитории — обучение для запуска
не требуется.

## Быстрый старт

```bash
cd forecast-container
docker build -t forecast-api .
docker run -p 8000:8000 forecast-api
```

Подробности — в [README решения](forecast-container/README.md).
